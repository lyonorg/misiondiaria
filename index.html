Instalar como app
Ícono en tu pantalla de inicio · datos guardados · funciona offline
Para tenerla como app real en tu iPhone: abre este archivo en Safari desde una URL pública (tu propio GitHub Pages / Netlify), toca el botón Compartir abajo, y elige «Añadir a pantalla de inicio». iOS la guarda como app: ícono propio, sin barra del navegador, tus datos y logros persisten indefinidamente y las notificaciones que le hayas activado te llegan aunque estés en otra app (requiere iOS 16.4 o superior). 🔄 Cómo actualizar la app · hosting permanente
⚠️ Si te apareció "site not found": era Netlify Drop sin cuenta. Esos sitios expiran a las 24–48h y se llevan tus datos con ellos. No es un bug de la app, es cómo funciona ese servicio "temporal".

✅ Solución definitiva → GitHub Pages con tu cuenta (lyonorg):
1. Ve a github.com/new desde tu computador.
2. Crea un repo llamado misiondiaria · déjalo público.
3. "Add file" → "Upload files" → sube el HTML pero renómbralo antes a index.html · commit.
4. Ve a Settings del repo → Pages (menú izquierdo).
5. En "Source" elige Deploy from a branch → branch main → carpeta / (root) → Save.
6. Espera 1–2 minutos. Tu URL fija será: lyonorg.github.io/misiondiaria.
7. Abre esa URL en Safari iPhone → Compartir → Añadir a pantalla de inicio.

Actualizar en el futuro: Vas al repo, "Add file → Upload files", reemplazas el index.html, commit. Tu iPhone recibe la versión nueva sin perder ningún dato porque el dominio es el mismo.

Alternativa aún más fácil: Cloudflare Pages (pages.cloudflare.com) también es gratis y permanente · sube el HTML directamente sin git.
